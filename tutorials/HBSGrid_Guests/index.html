    HBSGrid Guest Access: Account Setup and VPN Instructions

    First-Time Guests: Set Up Your Account and Access the HBSGrid

    Before You Begin

    Make sure you can access the email with the subject line “HBS Research Computing Environment Guest Account with Time-Sensitive Link.” You’ll use the link in this email to retrieve your temporary password.

    Step 1: Download Duo Mobile

    Install Duo Mobile on your smartphone. You’ll set it up in Step 2, after you activate your HBS Guest Researcher Account.

    • Duo Mobile for iPhone (iOS)
    • Duo Mobile for Android

    Step 2: Activate Your Account and Set Up Duo Mobile

    1. Retrieve your temporary password by clicking the link in the email titled “HBS Research Computing Environment Guest Account with Time-Sensitive Link.”
    2. Open the HBS sign-in page.
    3. Enter your new rcs_username email account in the Username field and your temporary password in the Password field. Select Sign In.

      🛑 Do not use the HarvardKey login button.

    4. When prompted, create a new password.

    Password requirements: Your password must: - Be at least 8 characters long. - Include at least 3 of these 4 character types: uppercase letters, lowercase letters, numbers, and special characters. - Contain no spaces. - Not contain 3 or more consecutive characters from your name or account name. - Not reuse a previous password.

    1. After changing your password, select Continue to Sign In.
    2. Select Log in Again.
    3. Enter your rcs_username email account and newly created password, then select Sign In.

      🛑 Do not use the HarvardKey login button.

    4. When prompted to set up Duo Security for multifactor authentication, select Get Started.
    5. Select Duo Mobile as your verification method.
    6. Enter your mobile phone number and select Continue.
    7. Check that your phone number is correct, then select Yes, it's correct. If needed, use the option to change your phone number.
    8. Confirm that Duo Mobile is installed on your smartphone, then select Next in your computer browser.
    9. Open Duo Mobile on your smartphone and tap Add (+) to add an account.
    10. Select Use QR Code in Duo Mobile and scan the QR code displayed in your computer browser.
    11. When your computer displays Added Duo Mobile, select Continue.
    12. Select I don't want to add more devices or Skip for now, depending on the screen, unless you want to register another verification method.
    13. When you see Setup Complete, select Log in with Duo.
    14. Approve the Duo verification request on your smartphone.

    After your account is created and Duo is activated, you’ll see a page that says “Access Denied.” This is expected. Continue to Step 3.

    Step 3: Install and Configure Ivanti VPN

    1. Download and install Ivanti for Windows or macOS, accepting all default settings.
    2. Open the Ivanti application on your computer.
    3. Check whether HBS VPN SSO is listed as a connection:
    4. If HBS VPN SSO is listed: Select it, then select Connect.
    5. If HBS VPN SSO is not listed: Select the + icon at the top of the screen to add a connection, using:
      • Name: HBS VPN
      • Server URL: https://vpnconnect.hbs.edu/sso
    6. Sign in with your HBS Guest Account and password, then approve the Duo Mobile push notification.

      🛑 Do not use the HarvardKey login button.

    Step 4: Get Started with the HBSGrid

    • Open the HBSGrid Quick Start Guide for instructions on accessing and using the HBSGrid.
    • Review the HBSGrid Storage Guide to learn how to access and manage your research files.

    Returning Guests: Update Ivanti VPN and Remove the Old Connection

    Install and Configure Ivanti Secure

    1. Install the updated version of Ivanti Secure for Windows or macOS, accepting all default settings.
    2. Open the Ivanti application on your computer.
    3. Check whether HBS VPN SSO is listed as a connection:
    4. If HBS VPN SSO is listed: Select it, then select Connect. Sign in with your HBS Guest Account and password, and approve the Duo Mobile push notification. > 🛑 Do not use the HarvardKey login button.

    5. If HBS VPN SSO is not listed: Select the + icon at the top of the screen to add a connection:

      • Name: HBS VPN
      • Server URL: https://vpnconnect.hbs.edu/sso

      Select Connect. Sign in with your HBS Guest Account and password, and approve the Duo Mobile push notification.

      🛑 Do not use the HarvardKey login button.

    Remove the Previous VPN Connection

    1. Open the Ivanti Secure Access Client.
    2. Confirm that HBS VPN SSO (https://vpnconnect.hbs.edu/sso) appears in the connection list and that you can successfully connect and sign in.
    3. Select HBS VPN (https://vpnconnect.hbs.edu).

      🛑 Do not select HBS VPN SSO.

    4. Select the X (delete) icon in the upper-right corner of the Connections section.
